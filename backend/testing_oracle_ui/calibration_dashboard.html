Failure Propagation: Propagation paths validated against execution graph. Risk severity justified by path count. Recovery strategies grounded in code.

Viva Realism: Questions assessed for specificity (vs generic trivia), grounding (evidence-backed), and architectural relevance. Generic patterns rejected.
